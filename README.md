### What I've built

**Social profiles platform** · Uber Eats\
Full-stack work across iOS, Go and web. I designed the Go services and storage for user media and reviews, and the Server-Driven UI entry points that let teams launch new surfaces without an app release.

**Interactive Live Activities** · Uber Eats\
A SwiftUI Live Activity, built on the app's RIBs architecture, that lets people rate their order from the lock screen. It appears automatically when an order is delivered and is live globally.

**WebView pre-warm layer** · iOS\
Because embedded web screens were slow to open, I built a reusable layer that prepares WebViews ahead of navigation so they appear instantly. Other teams adopted it for their own embedded surfaces.

**State-machine migration** · Uber Connect\
Led the iOS architecture (Swift Concurrency, Combine, Core Data) for moving package delivery onto a state-machine-based request flow, which meant aligning four platform teams. It cut app hangs and turned a multi-step checkout into a single backend-driven screen.

**End-to-end test automation** · iOS\
Replaced hundreds of brittle UI test scripts with a deterministic end-to-end framework and Grafana reporting, and ran workshops so other teams could adopt it.

**Multi-store checkout** · Uber Eats\
Lets customers combine items from several stores into one order. I built the iOS side across checkout, storefront and analytics, working with the teams that own each of those surfaces.

**Earlier:** real-time order tracking at Cornershop · Mobile Lead for iOS and Android at Mercadoni · Disney theme-park apps at Globant · co-founded Touchef, a private-chef marketplace (iOS, Android, Node.js, GraphQL).
